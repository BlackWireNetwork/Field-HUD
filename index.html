❓ FIELD MANUAL

Engineering-grade field guidelines and operational quick-start procedures.

📍 1. GPS Storing & Averaging

Tap STORE GPS to trigger a 5-second averaging countdown. The app records multiple epochs, averages the coordinates to cancel out multipath/jitter, and flags any point outside your QC Tolerance setting.

🔗 2. Smart Linework Coding

Linear features (e.g., EP, BOC, FL, TC, SW) automatically string together on the map. Use the modifier bar: tap B (Begin) on the first shot to start a fresh polyline string, and E (End) on the final shot to terminate it.

📡 3. RTK NMEA Bridge Setup

To feed high-precision RTK data from your GNSS receiver (Topcon/Trimble): pair via Bluetooth, open Lefebure NTRIP, set receiver output to TCP Server on port 50000. Field HUD's Python backend automatically streams true centimeter accuracy.

🧮 4. COGO Suite & Inverses

Select any two points on the map to activate the top selection bar. Tap INV for inverse bearing and horizontal distance, or STA/OFF to calculate station and offset relative to a baseline or CAD alignment.

📋 5. CAD Layers & Point Filters

Import GeoJSON vector and surface files (`.geojson`/`.txt`). Use the Layer & Point Filters Manager to toggle individual CAD layers or filter out point category types on the map overlay.

📡 RTK NMEA BRIDGE

To get True RTK Accuracy into Field HUD:

Step 1: Connect Receiver

Pair your Topcon/Trimble receiver via Bluetooth.

Step 2: Start Lefebure NTRIP

Open Lefebure. Go to Receiver Settings -> Output to TCP Server. Set the port to 50000.

Step 3: Connect

Once Lefebure has an RTK fix, it broadcasts raw NMEA. Field HUD's background Python server automatically connects to port 50000 and displays True Precision on the HUD.
